# เมนูของปรายใส

เว็บไซต์แนะนำเมนูอาหารเด็กจากวัตถุดิบที่มีในตู้เย็น

## ความสามารถ

- เลือกและค้นหาวัตถุดิบ
- จัดอันดับเมนูตามเปอร์เซ็นต์วัตถุดิบที่มี
- แสดงวัตถุดิบที่ขาด วิธีทำ เนื้อสัมผัส และสารก่อภูมิแพ้
- กรองตามช่วงวัยและมื้ออาหาร
- รองรับโทรศัพท์และคอมพิวเตอร์

เว็บไซต์นี้เป็นแนวทางทั่วไป ผู้ปกครองควรปรับอาหารตามพัฒนาการและประวัติแพ้อาหารของเด็ก
